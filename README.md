# 생각이 만나는 미술관 · 최신 버전

세 영역, 공통 9단계, 단계별 질문 하나와 응답 칸 하나를 제공합니다.
그림 모두 지우기는 확인창 없이 현재 활동 캔버스와 저장된 그림을 비웁니다.
이전으로 되돌리기는 마지막 10번의 그리기·지우기 작업을 취소합니다. 되돌리기 이력은 페이지를 새로고침하면 초기화됩니다.

## GitHub Pages 업로드
1. 압축을 풉니다.
2. index.html, app.js, lessons.js, clean9.css, pop.css, .nojekyll을 저장소 최상위에 함께 업로드합니다. 기존 파일은 교체합니다.
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. 배포 완료 후 접속합니다. 이전 화면이 보이면 Ctrl+Shift+R로 새로고침합니다.

별도 설치 또는 API 키는 필요하지 않습니다. AI 도우미는 교사와 함께 별도 ChatGPT 창에서 사용합니다. 기록은 현재 기기의 브라우저에 저장되며 JSON 저장·불러오기를 지원합니다.
